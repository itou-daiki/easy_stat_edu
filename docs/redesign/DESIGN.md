# easyStat デザイン刷新（2026-10）

## 目的
探究の流れ「問い → データ → 手法 → 結果 → 解釈」を、統計の教科書や研究レポートのように上から順に読めるようにする。
SaaS のランディングページ風（グラデーションのヒーロー、色付きアイコンタイル、影付きカード、ピル型ボタン）をやめ、
文字の大きさ・余白・細い罫線で階層を作る。初学者モード（Q1〜Q3 の設問・下線タブ・左罫線の判断パネル）を基準とし、アプリ全体をそれに合わせた。

- アクセントは 1 色のみ。意味色は有意・注意・エラーのときだけ使う。グラデーションなし。

## 文字
- `--font-sans`: BIZ UDPGothic（Google Fonts、400/700）→ Hiragino Sans → Noto Sans JP …。700 までのため、ロゴだけ `-webkit-text-stroke` で太らせる。
- 本文 16px、行間 1.7。スケール: 13 / 14 / 16 / 18 / 22 / 28px（`--text-xs`〜`--text-xl`）。
- 表と統計値は `font-variant-numeric: tabular-nums`（桁がそろう）。
- グラフと表は `--font-serif`（Times New Roman ＋明朝）。UI の設問番号はゴシック。

## 部品
- **ヒーロー**（2026-10 v3）: 画面幅いっぱいのドジャーブルー（#1e90ff）の面（PC 約 216px、スマホ約 190px）。左下に白いアプリ名（52px／スマホ 34px）とキャッチコピー（20px 太字／スマホ 19px 太字）。どちらも「大きな文字」なので 3.24:1 で可。右上に言語切替（#0f5fa8 の台に白文字、選択中は白地に #0f5fa8）とマニュアル（白いボタンに #0f5fa8）。右側に散布図と回帰直線をかたどった白い細線（不透明度 8%、SVG の data URI）を敷く。文字と重ならないよう 1200px 未満では出さず、キャッチコピーは最大 38rem で折り返す。作者表記（小さな文字）は帯の下に右寄せ。帯は `box-shadow: 0 0 0 100vmax` ＋ `clip-path` で左右へ伸ばし、横スクロールを生まない。帯の上のフォーカス輪郭は白。マニュアル（manual.html）の上部バーも同じ青。
- **紙面**: 白地＋1px の青みの罫線＋16px 角丸＋`--shadow-card`。ページ地は #f4f8fd。
- **文字の段階**: 32px（分析機能を選択・分析ページ名）/ 24px（設問 Q1〜Q3）/ 20px（データ情報・分類見出し）/ 16px（本文）。
- **節見出し**: 「分析機能を選択」「データ情報」「手法の選び方」は左に 4px（3px）のドジャーブルーの印。見出しは字間 0.02em。分析一覧の分類見出しの下罫線、分析ページ見出しの下罫線（3px）もドジャーブルー。分析結果の節見出しのアイコンは基調色。
- **折りたたみ**: 見出し 16px 太字、アイコンと開閉の印は `--accent`。hover は `--accent-hover`。
- **分析一覧**（すべての手法から選ぶ）: 目次のように「分類見出し＋青の罫線 → 手法名（太字）＋1 行説明＋→」。hover で淡い青の面と、→ が 3px 進む。
- **初学者モード**: Q1〜Q3 は 40px のドジャーブルー（#1e90ff）の丸に白い 19px 太字（大きな文字、3.24:1）。選択肢はカード（16px 角丸）。hover で 2px 浮き、選択中は #eaf4ff の面＋2px のドジャーブルー枠＋左 4px の帯＋手法名を濃い青に（ラジオの印と合わせて色だけに頼らない）。データのヒントは淡い青の面＋左罫線。「手法の選び方」は淡い青の欄に角丸の表（見出し行 #eaf4ff）。
- **モードタブ・データ入力タブ**: 下線タブ。選択中は濃い青の文字＋3px のドジャーブルー下線、hover で淡い下線。
- **判断パネル**（`.guided-decision`）: 白地＋青みの枠＋左 4px のドジャーブルー、見出し上の小見出しは濃い青。ボタンは 14〜15px の文字なので、塗りは #1670c9、枠のボタンは 2px のドジャーブルー枠。
- **分析ページの見出し**: 淡い青（#eaf4ff）の見出し面（16px 角丸）に、分析名を 32px 太字の #0f5fa8（5.86:1）、説明は #374151（9.27:1）。概要イラストはその下。
- **フッター**: 濃い青（#0f5fa8）の帯を左右と下の端まで。文字とリンクは白（6.52:1）、リンクは下線つき。
- **ボタン**: 主要ボタン（ファイルを選択・分析する・各分析の実行）＝ #1e90ff の塗りに 19px 太字の白（大きな文字のため 3.24:1 で可）、12px 角丸、ゆったりした余白、淡い青の影。hover #1670c9（5.01:1）、押すと 1px 沈む。「分析する」は右に →（読み上げない）が hover で進む。副ボタン（デモデータを試す等）＝白地に #1670c9 の文字（5.01:1）＋2px の #1e90ff 枠。それ以外の小さな文字のボタンは従来どおり #1670c9 の塗り。戻る＝テキストリンク。分析の実行ボタンは全手法で同じ色。
- **表**: 論文の表（上下 2px の本文色罫線、見出し下 1px、縦罫なし）。APA 表は従来どおりセリフ体。Plotly のグラフ本体（白地・セリフ体）は変えない。
- **データ情報・サンプルサイズ**: カードをやめ、「項目 / 値」を罫線で区切った定義リスト（`.file-info-list` `.sample-size-list`）。

## 分析モジュールのインラインスタイル
25 のモジュールは同じインラインスタイル（`background: #1e90ff` の見出し帯、影付きの白カード等）を持つ。
同時に別の作業が進んでいるため、モジュールを一つずつ書き換えず、`css/style.css` の「分析画面のデザイン層」で
`#analysis-content [style*="…"]` を使って上書きしている（この節だけ `!important`）。
将来はモジュールのテンプレートを `.analysis-title-banner` などのクラスへ置き換え、この層を削除するのが望ましい。
（`tests/unit/layout_consistency_validation.spec.ts` は `background: #1e90ff` の文字列の存在を検査しているため、置き換える際はテストも更新が必要。）

## アクセシビリティ
- すべての操作要素に 3px の `:focus-visible` 輪郭。
- 選択状態は色だけでなく左罫線・下線・太字で示す。
- 動きは hover・focus の 120〜180ms の遷移だけ。`prefers-reduced-motion` で止める。
- グラデーション・ぼかし・絵文字・色付きアイコンタイルは使わない。
- 375px 幅で横スクロールなし（表は `.table-container` 内でスクロール）。印刷用スタイルは従来どおり。
