# easyStat デザイン刷新（2026-10）

## 目的
探究の流れ「問い → データ → 手法 → 結果 → 解釈」を、統計の教科書や研究レポートのように上から順に読めるようにする。
SaaS のランディングページ風（グラデーションのヒーロー、色付きアイコンタイル、影付きカード、ピル型ボタン）をやめ、
文字の大きさ・余白・細い罫線で階層を作る。初学者モード（Q1〜Q3 の設問・下線タブ・左罫線の判断パネル）を基準とし、アプリ全体をそれに合わせた。

- アクセントは 1 色のみ。意味色は有意・注意・エラーのときだけ使う。グラデーションなし。
- 角丸 `--radius-sm` 4px / `--radius` 6px。影は浮かぶ要素（ドロップダウン・モーダル・AI パネル）だけ。
- 旧変数（`--primary-color` など）は新トークンへの別名として残し、既存ルールが自動で新配色になる。

## 文字
- `--font-sans`: Inter → Hiragino Sans → Noto Sans JP → Yu Gothic UI → Meiryo。和文は OS の良いゴシックに落ちる。
- 本文 16px、行間 1.7。スケール: 13 / 14 / 16 / 18 / 22 / 28px（`--text-xs`〜`--text-xl`）。
- 表と統計値は `font-variant-numeric: tabular-nums`（桁がそろう）。
- 設問番号・手順番号だけ `--font-serif`（教科書の番号のような手触り）。

## 部品
- **アプリバー**（旧ヒーロー）: アプリ名＋説明＋作者、右に言語切替とマニュアル。下罫線 1 本。`.hero-*` のクラス名は維持。
- **節**: 白地＋1px 罫線＋6px 角丸。折りたたみ見出しは 16px 太字、アイコンは灰色・小さく、開くと下罫線。
- **分析一覧**（すべての手法から選ぶ）: 目次のように「分類見出し＋太罫 → 手法名（太字）＋1 行説明＋→」。色タイル・サムネイルは廃止。
- **分析ページ**: 青い帯 → 「ページ見出し 28px＋1 行説明＋2px の本文色罫線」。節見出しは本文色、結果の節は上罫線で区切る。
- **ボタン**: 主操作＝濃いめのドジャーブルー（--accent）の塗り、副操作＝枠線、戻る＝テキストリンク。浮き上がる hover・影は廃止。分析の実行ボタンは全手法で同じ色。
- **タブ**: データ入力・EDA・データ加工・テキストマイニングとも下線タブ（初学者モードと同じ形）。
- **表**: 論文の表（上下 2px の本文色罫線、見出し下 1px、縦罫なし）。APA 表は従来どおりセリフ体。
- **データ情報・サンプルサイズ**: カードをやめ、「項目 / 値」を罫線で区切った定義リスト（`.file-info-list` `.sample-size-list`）。

## 分析モジュールのインラインスタイル
25 のモジュールは同じインラインスタイル（`background: #1e90ff` の見出し帯、影付きの白カード等）を持つ。
同時に別の作業が進んでいるため、モジュールを一つずつ書き換えず、`css/style.css` の「分析画面のデザイン層」で
`#analysis-content [style*="…"]` を使って上書きしている（この節だけ `!important`）。
将来はモジュールのテンプレートを `.analysis-title-banner` などのクラスへ置き換え、この層を削除するのが望ましい。
（`tests/unit/layout_consistency_validation.spec.ts` は `background: #1e90ff` の文字列の存在を検査しているため、置き換える際はテストも更新が必要。）

## アクセシビリティ
- すべての操作要素に 3px の `:focus-visible` 輪郭。
- 選択状態は色だけでなく左罫線・下線・太字で示す。
- `prefers-reduced-motion` でアニメーション・遷移を止める。
- 375px 幅で横スクロールなし（表は `.table-container` 内でスクロール）。印刷用スタイルは従来どおり。
