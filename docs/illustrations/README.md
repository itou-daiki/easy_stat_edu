# 説明イラストの作り方

各分析の画面で、見出しのすぐ下に表示する説明イラスト（23枚）は、`tools/illustrations/` のプログラムで描いています。

## なぜプログラムで描くのか
画像生成AI（Antigravity・ChatGPT）でも試しましたが、次の理由でプログラムに切り替えました。

- 「平均80点」と書いた山を約92点の位置に描くなど、**数値と図の位置がずれる**
- 生徒は図をそのまま信じるため、ずれた図は誤解のもとになる

図の構成（生徒の問い → 2つの例を並べた図 → 読み方 → 1行のまとめ）は、ChatGPTとのやり取りと、ChatGPTによる「統計を初めて学ぶ高校2年生」の立場からの批評をもとに決めています。

## 図の約束
- **上：生徒の問い**。見ただけ（引き算だけ）で答えられる問いにしない（例：「6点の差は『たしかな差』といえる？」）
- **左右は別の例**であることと、そろえた条件（人数・平均など）を明記する
- **点1つが1人**。横の位置が値で、同じくらいの値の人は上に積む
- 結論は「○○で計算すると…」と書き、「いえない」側には「『同じ』とわかったわけではありません」を添える
- 色はドジャーブルー（#1e90ff）とオレンジ（#e8710a）＋グレー。グラデーション・影・飾りは使わない

## 正しさの確認
図に使うデータはすべてプログラムの中で作り、`verify.py` で実際に検定して、図の説明（「いえる」「いえない」）と結果が合っていることを確かめています（28項目）。

## 作り直し方
```bash
python3 tools/illustrations/verify.py             # 図のデータで検定し、説明と合うか確かめる（要 scipy・statsmodels）
python3 tools/illustrations/build_illustrations.py # image/illustrations/*.svg を作る
node tools/illustrations/render_png.cjs           # アプリで表示する PNG（1600×900）を作る
```

| ファイル | 内容 |
|---|---|
| `svgkit.py` | 描画の道具、共通レイアウト、例データの作り方 |
| `fig_compare.py` | t検定・分散分析（一要因・二要因）・U検定・クラスカル・ウォリス・ウィルコクソン |
| `fig_relation.py` | 相関・単回帰・重回帰・ロジスティック回帰・主成分分析・時系列 |
| `fig_category.py` | クロス集計・カイ二乗検定・フィッシャー・マクネマー |
| `fig_data.py` | 探索的データ分析・データ加工・データ結合・因子得点・因子分析・テキストマイニング・分析サポーター |
