# 初学者モード（おまかせ分析）実装プラン

## 背景
生徒から「どの分析を選べばいいかわからない」という声。手法名（t検定、U検定…）から選ぶUIは初学者には難しい。

## ゴール
1. ホーム画面をデフォルトで **初学者モード** にする（「すべての分析から選ぶ」モードへ切替可能、選択は保存）。
2. 初学者モードでは手法名ではなく **やりたいこと** で選ぶ。
   - 平均値を比較する
   - 2つの数値の関係を調べる
   - 人数・割合の偏りを調べる
   - 数値から数値を予測する
   - データの全体像を見る
3. 変数を選んで「分析する」を押すと、前提チェック（正規性の検定など）を自動で行い、適切な手法を選んで実行する。
4. 結果画面の上部に「なぜこの手法を選んだか」（チェック結果と判断の流れ）を表示する。

## 判断ルール
| やりたいこと | データ | 条件 | 選ばれる手法 |
|---|---|---|---|
| 平均値を比較 | 別々のグループ・2群 | 全群で正規性あり（Shapiro-Wilk p ≥ .05） | 対応なしt検定（Welch） |
| | | 正規性なし / n<3 の群あり | Mann-Whitney U検定 |
| | 別々のグループ・3群以上 | 正規性あり | 一要因分散分析（Leveneは参考表示） |
| | | 正規性なし | Kruskal-Wallis検定 |
| | 同じ人・2回 | 差の正規性あり | 対応ありt検定 |
| | | 差の正規性なし | Wilcoxon符号付順位検定 |
| | 同じ人・3回以上 | 全条件で正規性あり | 反復測定分散分析 |
| | | 正規性なし | Wilcoxon検定（Holm補正の多重比較） |
| 関係 | 数値×数値 | 両方正規性あり | Pearson相関 |
| | | どちらか正規性なし | Spearman相関 |
| 人数・割合 | カテゴリ×カテゴリ | 期待度数5未満のセルが20%超 or 1未満あり（2×2は1つでも5未満） | Fisherの正確確率検定 |
| | | それ以外 | カイ二乗検定 |
| 予測 | 数値→数値 | （残差の正規性を参考表示） | 単回帰分析 |
| 全体像 | — | — | EDA |

## 実装
1. `js/utils/normality.js` — Shapiro-Wilk 検定（Royston 1995 / AS R94）、正規分布CDF・分位点。純粋関数。
2. `js/utils/method_selector.js` — 上表の判断ロジック（純粋関数、チェック結果と理由を返す）。
3. `js/guided_mode.js` — ホームの初学者モードUI（目的 → 変数選択 → 分析する）、モード切替、既存分析モジュールへの変数プリセットと自動実行、判断理由パネル。
4. `main.js` — `showAnalysisView(type, options)` にプリセット実行フックを追加。モード切替の初期化。
5. `utils.js` — マルチセレクトに値をプログラムから設定する `setMultiSelectValues()`。
6. `css` — 初学者モードのスタイル。
7. 日英両対応（`getLocale()` と `easystat:localechange`）。

## テスト
- `tests/unit/normality.spec.ts` — scipy.stats.shapiro の既知値と照合。
- `tests/unit/method_selector.spec.ts` — 判断ルールの分岐。
- `tests/guided_mode.spec.ts` — E2E：デフォルトが初学者モード、各目的で自動実行・判断理由表示、モード切替の保存。
- 既存スモークテストの回帰確認。
